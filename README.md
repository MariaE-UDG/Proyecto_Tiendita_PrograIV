# TrendMode MX - Tiendita Full-Stack

Proyecto de tienda de ropa con persistencia en archivos CSV, API REST con FastAPI y Pandas, y Dashboard con Chart.js.

## Tecnologías
- Backend: Python, FastAPI, Pandas
- Frontend: HTML, CSS (Bootstrap), JavaScript
- Base de datos: Archivos planos (productos.csv, ventas.csv)
- Gráficas: Chart.js

## Cómo ejecutar
1. Instalar dependencias: `pip install fastapi uvicorn pandas pydantic`
2. Iniciar servidor: `uvicorn main:app --reload --port 8000`
3. Abrir `index.html` en el navegador.
